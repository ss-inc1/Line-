YouTube運営の「考える・書く・振り返る」を支援するYouTube Agent Skill。11個のスキルを目的別に使い分け、チャンネルの実データと自分の経験をもとに、次の動画を作る手順をまとめました。

11スキル一覧導入手順運用フローFAQ

11スキルを、作業の流れで見る

このツールは動画を勝手に作って公開するものではありません。企画書・台本案・チェックリストを作り、人が確認して撮影・編集・公開するための作業支援です。

企画と台本/yt-script：冒頭フック案と台本づくり。型を参考に複数案を出し、採用案は人が選ぶ。
タイトル・サムネ/yt-package：タイトルとサムネの約束が一致しているか整理・点検。
編集メモ/yt-edit：文字起こしから、間・言い直しなどの候補をタイムコード付きでまとめる。
コメント/yt-comment：コメントの分類、返信案、固定候補を整理。返信や固定は自分で確認。
投稿計画/yt-plan：本編とShortsを含む週次計画案を作る。
同ジャンル分析/yt-viral：公開動画の再生数を各チャンネルの通常水準と比べ、伸び方の候補を探る。
視聴維持/yt-retention：YouTube Studioの維持率データと文字起こしを照合し、離脱箇所の仮説を出す。
Shorts再構成/yt-shorts：長尺の素材から短尺向けの構成・切り出し候補を整理。
検索向け整理/yt-seo：検索語や概要欄の整理を支援。タグだけで再生が伸びるものではない。
チャプター/yt-chapters：文字起こし等から章立てと時刻案を作る。
公開前監査/yt-audit：台本・タイトル・概要欄などの抜けをチェック。

導入から初回の台本まで

01

Claude Codeを開いてプラグインを追加

目的：YouTube用の作業コマンドを使える状態にするためです。

Claude Codeを起動し、プラグインのマーケットプレイスを登録してからYouTube Agentをインストールします。動画の説明にある2つのコマンドを順番に入力します。

/plugin marketplace add Jakeschincariol/youtube-agent-skill
/plugin install youtube-agent

導入後、Claude Codeを再起動または指示どおり再読み込みし、コマンド一覧に各ytコマンドが出るか確認します。コマンドが見つからない場合は、プラグインの導入状態とClaude Codeの案内を確認してください。

チェック：プラグインが読み込まれ、使用可能なスキルが見えていますか？
02

チャンネルの声と根拠を渡す

目的：誰向けの動画か、何を事実として言えるかを揃えるためです。

視聴者、テーマ、過去動画の文字起こし、自分の経験、使ってよい根拠を短いメモにします。経験していないこと・確認できない数字は台本に足さない、と最初に指定します。

テーマ：
想定視聴者：
視聴者が困っていること：
この動画で約束すること：
自分が実際に経験・確認した事実：
根拠として使える資料やデータ：
言ってはいけないこと・誇張表現：
最後に視聴者にしてほしい行動：

この情報だけを根拠に台本案を作ってください。
不明点は質問し、数字・体験・成果を創作しないでください。
チェック：テーマと視聴者だけでなく、裏付け可能な事実も渡しましたか？
03

台本案を比べ、タイトルとサムネを揃える

目的：思いつきで決めず、動画の中身と約束が合う企画を選ぶためです。

台本コマンドにテーマ・視聴者・根拠を渡して複数の冒頭案を出します。採点は選択肢を比べる補助として使い、点数を再生数の予測と考えないでください。候補を決めたらタイトルとサムネをセットで作り、動画内で実際に答えを渡しているか確認します。

/yt-script
上の企画メモを使い、冒頭フックを複数案出してください。
各案について、誰のどんな悩みに届くか、動画で回収する答え、
事実確認が必要な文を示してください。
採用案を決めるのは人です。再生数を保証する表現は不要です。

/yt-package
採用した台本に合うタイトルとサムネの組み合わせを複数提案。
視聴者に約束する内容が一致しているか点検してください。
チェック：タイトルやサムネが動画の中身を誇張していませんか？
04

編集メモと公開後の振り返りに使う

目的：編集・改善で見るべき箇所を、具体的な時間と根拠で見つけるためです。

文字起こしを使って編集候補を出し、映像を見ながら採否を決めます。不要な間と判断された箇所も、演出や文脈に必要なら残します。公開後はStudioのデータを出し、どの場面で視聴が落ちたかを言葉と照合。改善仮説を次の台本に反映します。

/yt-edit
この文字起こしから、間・言い直し・重複の編集候補を
タイムコード付きで表にしてください。
文脈上残した方がよい可能性も併記し、映像未確認の箇所は
「要確認」と明記してください。

/yt-retention
視聴維持率データと文字起こしを照合し、
落ち込み箇所・該当発言・考えられる仮説・次に試す変更を整理。
データから断定できない理由は仮説として分けてください。
チェック：提案されたカットを映像で確認し、数値と仮説を区別しましたか？

「作って終わり」にしない運用の型

公開後に見る順番

  1. 表示回数とクリック率：サムネ・タイトルが視聴者に伝わったかを検討。
  2. 冒頭の維持：クリック後に、約束した話へ早く入れているか確認。
  3. 離脱箇所と発言：グラフだけで原因を断定せず、その場面の内容も見る。
  4. 次の一本で一つ変える：冒頭、構成、長さなどを一度に変えすぎず比較する。

数値はチャンネル規模・テーマ・視聴者によって異なります。特定の数値を正解として追うのではなく、自分の過去動画と比べて改善仮説を立てます。

週の作業例

月：公開データを振り返り、次の題材候補を選ぶ。火：台本案を比較し、根拠を確認。水：撮影・編集、カット案を目視確認。木：タイトル・サムネの組み合わせを点検。金：公開準備とコメント案の確認。Shortsに再構成する場合も、元動画の文脈を誤解させないか確認します。

分析で守ること

同ジャンルの公開動画を見るときは、チャンネルの通常再生数と比較した伸び方を参考にします。再生数の倍率は題材候補を探す指標で、成功の保証ではありません。構成や切り口を学び、台本や映像をそのままコピーしないこと。コメント返信・公開・動画編集は人が内容を確認して行います。

よくある質問

無料で使えますか？

配布元のプロジェクトは公開ソースとして案内されています。Claude Code自体の利用条件・プラン・利用上限は別に確認してください。

YouTubeに自動で投稿されますか？

いいえ。スキルは企画や文章、分析の補助です。動画の書き出し・最終確認・アップロード・公開は自分で行います。

11個を全部使う必要がありますか？

ありません。最初は台本かタイトル・サムネなど、今詰まっている作業から使い、役立つものだけ残します。

フックの点数が高ければバズりますか？

保証にはなりません。点数は案を比較する目安にとどめ、視聴者との相性や動画内容、公開後の実データで判断します。

他チャンネルの動画を真似していいですか？

再生の伸び方や構成の特徴を分析材料として使います。台本・映像・独自表現をコピーせず、自分の経験と視聴者に合わせて作り直します。
